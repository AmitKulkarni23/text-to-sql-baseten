# TextToSQL

Ask a database a question in plain English and get back the SQL and its results. The SQL is written by a small open model (Qwen2.5-Coder-1.5B) fine-tuned for text-to-SQL and served on [Baseten](https://www.baseten.co/). The model is measured against its base model and a large hosted model on accuracy, latency and cost.

Work in progress: see `docs/task-specs/TASK_INDEX.md`. Results, costs and tradeoffs land here when it ships.
